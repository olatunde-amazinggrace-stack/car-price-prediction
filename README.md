CAR PRICE PREDICTION

Project Overview
This project builds a machine learning model to predict the selling price of used cars based on their features.

BUSINESS PROBLEM
An online car marketplace wants to estimate the selling price of used cars accurately using historical vehicle data.

Target Variable
Selling Price

FEATURES
* Car_Name
* Year
* Present_Price
* Kms_Driven
* Fuel_Type
* Seller_Type
* Transmission
* Owner

STEPS TAKEN
1. Problem Understanding
2. Data Exploration (EDA)
3. Data Preprocessing
4. Linear Regression Model Building
5. Model Evaluation
6. Prediction of Sample Cars

 Evaluation Metrics
* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* R² Score

HOW TO RUN
1. Open the notebook in Google Colab.
2. Upload the dataset if needed.
3. Run all cells from top to bottom.
4. View the model results and predictions.

 Files Included
* Car_Price_Prediction.ipynb
* cleaned_car_dataset.csv
* README.md
